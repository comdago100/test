# 제품정보·목록 페이지·검사성적서 사용 안내

## 제품정보

입력 순서는 **PO번호 → PO 라인번호 → 품명 → 사이즈 → 재질 → 수량 → 적용 규격 → 요구 선급 → 도면번호 / Rev. → 기타정보**입니다.

| 항목 | 입력 기준 |
| --- | --- |
| PO번호 / 라인번호 | 고객 주문서 번호와 주문서의 행 번호. `0010` 같은 앞자리 0을 유지합니다. 생산 라인명이 아닙니다. |
| 품명 / 사이즈 / 재질 | 제품명, 치수·호칭, 재질 등급 |
| 수량 | 수주에서는 주문 개수, 작업지시에서는 이번 작업 목표 개수 |
| 적용 규격 / 요구 선급 | 적용 표준과 고객이 요구한 선급. 선급명 입력이 승인·인증을 의미하지는 않습니다. |
| 도면번호 / Rev. / 기타정보 | 도면 개정번호와 추가 요구사항 |

1. **품목 등록**에서 기본 사양을 저장합니다. PO·라인·수량은 수주와 작업지시에서 입력합니다.
2. **수주 관리**에서 품목을 고르면 기본 사양이 채워집니다. 이번 고객 주문의 PO와 조건을 확인해 저장합니다.
3. **작업지시 생성**은 해당 수주에 저장된 제품정보를 복사합니다. 수량은 미지시 잔량 안에서 나누어 발행할 수 있습니다.

품목 사양을 수정해도 이미 저장한 수주·작업지시는 바뀌지 않습니다. 수주를 수정해도 기존 작업지시에 자동 반영되지 않습니다. 필요한 문서를 직접 수정하세요. 이미 발행한 검사성적서 내용은 보존됩니다.

## 목록을 페이지로 보기

주요 목록에서 **5·10·20·50개씩 보기**를 선택합니다. 처음에는 10개이며 선택한 보기 수는 같은 브라우저의 각 화면에 저장됩니다. 처음/이전/다음/마지막 또는 페이지 번호로 이동합니다. 검색·필터를 바꾸면 첫 페이지로 돌아갑니다.

합계와 엑셀은 한 페이지가 아니라 **검색 조건에 맞는 전체 자료**를 기준으로 합니다. 수불 이력은 기존 100건씩 조회 방식을 유지합니다.

## 검사성적서 작성과 출력

1. **검사성적서 → 새 성적서 작성**을 누릅니다. 작업지시 카드의 **검사성적서**에서 열면 해당 지시가 선택됩니다.
2. 고유 성적서 번호·작업지시·제조사·검사일·발행일·검사자·확인자를 입력합니다. 제품정보와 용해/로트는 초안을 저장할 때 작업지시에서 복사합니다.
3. **대상 로트수량**과 **실제 검사수량**을 구분합니다. 납품 대상 17개 중 5개를 검사했다면 로트 17, 검사 5입니다. 검사수량 ≤ 로트수량 ≤ 작업지시 목표수량이어야 합니다.
4. **외관·치수 양식** 또는 **주물 재질 양식**으로 시작합니다. 화학성분·기계적 성질·비파괴 등 검사 항목을 추가·삭제·이동할 수 있습니다. 양식 교체 시 기존 항목과 결과가 지워집니다.
5. 각 항목의 **검사명·기준/허용값·실측 결과·판정**을 입력합니다. 방법·단위·비고도 필요한 만큼 기록합니다. 기준과 측정값은 적용 규격과 실제 검사 결과를 사용합니다.
6. **초안 저장** 후 목록에서 내용을 확인하고 **성적서 발행**을 누릅니다. 누락된 결과는 발행할 수 없습니다. 불합격 항목이 하나라도 있으면 종합 불합격입니다. 해당 없음은 결과와 비고에 사유가 필요합니다.
7. **성적서 / 인쇄 → 인쇄 / PDF 저장**에서 출력합니다. 초안·취소 문서는 그 상태가 표시됩니다.

### 발행 후 정정

발행본은 직접 수정하지 않습니다. **취소 / 삭제**에서 사유를 기록한 후 **항목 복사 (결과 초기화)**로 새 번호의 성적서를 작성합니다. 복사 시 측정 결과·판정·검사수량은 다시 입력합니다. 원본과 변경 이력은 보관됩니다. 과거 이력은 참고용입니다.

성적서 발행은 기존 검사 완료·불량·출고·재고 수량을 자동 변경하지 않습니다. 실제 생산과 불량 실적은 **현장 스캔**에서 기록하세요. 취소 성적서를 포함해 성적서가 연결된 작업지시는 삭제를 막아 근거를 보존합니다.

이 양식은 자체 검사 결과용입니다. 제조사·발주·재질·치수·수량·시험 결과·발행일 구성은 [SSAB 검사문서 안내](https://www.ssab.com/-/media/files/en/hardox/155--en--hardox-guarantees--v4--2024.pdf)를 참고했습니다. 공식 선급 승인서나 EN 10204 3.1/3.2 인증서를 대체하지 않습니다. 외부 시험 결과를 인용할 때는 시험기관과 성적서 번호를 기록하세요.

## 관리자 설정

경량 ERP까지 적용된 기존 DB에는 **[product_inspection.sql](../supabase/product_inspection.sql) 전체만 Supabase SQL Editor에서 실행**합니다. 새 설치는 `light_erp.sql` 다음에 실행합니다. 웹 공개 키에는 테이블 생성 권한이 없습니다.

새 SQL은 반복 실행해도 기존 제품정보·성적서와 발행본을 보존합니다. 제품정보 확장 후 구버전 `light_erp.sql`을 단독 재실행하지 마세요. 이전 수주 뷰의 열 순서가 달라집니다. 기존 스캔·불량·재고 계산은 유지합니다. 페이지 기능 자체에는 SQL이 필요 없습니다.

제품정보는 품목·수주·작업지시의 JSON 상세정보로 저장하고, 성적서는 작업지시 참조키와 문서 사본·변경 이력을 보존합니다. 저장 RPC는 요청 UUID로 중복을 막고 수정 버전을 검사합니다. 목록은 현재 원본 전체를 조회한 뒤 페이지로 나누어 표시합니다.
