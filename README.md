# 2022년 제조업 재고수불부

원재료·부재료·제품 엑셀 9개를 읽어 수불을 계산하고, 기업 표준 A4 가로 인쇄 양식을 적용한 엑셀 4개 시트를 출력하는 Windows 데스크톱 앱입니다. Python 3.10+, PySide6, pandas, openpyxl, numpy를 사용합니다.

## 실행 및 사용

빌드한 `dist/InventoryLedger2022.exe`는 Python 설치 없이 실행합니다. 소스로 실행하는 PowerShell 명령은 다음과 같습니다.

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -e '.[build]'
.venv/Scripts/python -m inventory_ledger
```

1. 회사명을 입력하고 결재란 포함 여부를 선택합니다.
2. 9개 파일을 개별 선택하거나 **폴더 일괄 로드**합니다.
3. **1단계: 데이터 검증 실행**을 누릅니다. 결과는 **데이터 검증 결과** 탭에서 확인합니다.
4. 오류를 수정하고 품목 미일치 등 확인 항목을 검토합니다. 검증 통과 시 2단계 버튼이 활성화됩니다.
5. **2단계: 인쇄용 수불장 엑셀 생성**을 누르고 저장합니다. 진행 표시바에 처리 진행률이 표시됩니다.
6. Excel에서 생성 파일을 열어 Ctrl+P로 인쇄합니다.

입력 경로가 바뀌면 2단계 버튼이 비활성화됩니다. 출력 직전에도 원본을 다시 읽고 검증하므로 같은 경로의 파일 내용이 바뀌어도 오류를 차단합니다. 입력 파일을 출력 파일로 덮어쓸 수 없습니다. 작업 실패 시 기존 출력 파일을 보존합니다.

## 실제 입력 열 구조

`.xlsx`, `.xlsm`의 첫 시트, 첫 행을 열 제목으로 읽습니다. 열 이름과 텍스트의 앞뒤 공백을 제거합니다. 날짜 열 이름으로 `일자`를 요구하지 않습니다. `단위` 열도 필요하지 않습니다. 구형 `.xls`는 Excel에서 `.xlsx`로 저장해 주세요. 빈 파일은 필수 열 제목만 남겨두면 됩니다.

| 계정 | 파일 | 필수 열 |
| --- | --- | --- |
| 원재료 | 이월 | 재질, 수량, 단가, 금액 |
| 원재료 | 입고 | 입고일, 재질, 수량, 단가, 금액 |
| 원재료 | 재고 | 재질, 수량, 단가, 금액 |
| 부재료 | 이월 | 품명, 규격, 수량, 단가, 금액 |
| 부재료 | 입고 | 입고일, 품명, 규격, 수량, 단가, 금액 |
| 부재료 | 재고 | 품명, 규격, 수량, 단가, 금액 |
| 제품 | 이월 | 공장, 품명, 규격, 수량, 금액 |
| 제품 | 출고 | 출고일, 공장, 품명, 규격, 수량 |
| 제품 | 재고 | 공장, 품명, 규격, 수량, 금액 |

- 품목 키: 원재료 `재질`, 부재료 `(품명, 규격)`, 제품 `(공장, 품명, 규격)`. 다른 공장의 같은 제품은 별도 품목입니다. 단순 문자열 연결로 키 충돌을 만들지 않습니다.
- 이월 일자는 `2022-01-01`, 재고 일자는 `2022-12-31`로 지정합니다. 제품 이월·재고의 단가는 수량이 양수일 때 금액/수량으로 계산합니다.
- 제품 출고는 수량만 읽으며 단가·금액을 기준단가로 계산합니다. 추가로 들어 있는 출고단가·금액도 계산 기준으로 사용하지 않습니다.
- 수량·금액은 콤마와 앞뒤 공백을 제거하고 **Python `round() → int`**로 정수화합니다. 예: `129096.0001 → 129096`, `"1,000.6" → 1001`. 정확히 `.5`이면 Python의 짝수 쪽 반올림을 적용합니다(`2.5 → 2`, `3.5 → 4`). float로 재변환하지 않아 추가 이진 부동소수점 오차를 만들지 않습니다. 단가는 소수를 유지합니다.
- 원·부재료는 원본 금액을 우선하며 단가 또는 금액 값 중 하나가 공란이면 다른 값으로 계산할 수 있습니다. 정수화 후의 수량·금액과 단가는 0 이상이어야 합니다. 수량 0/금액 양수, 음수 반품 거래는 오류입니다.
- 수식 셀은 Excel에 저장된 계산 결과를 읽어 같은 정수화를 적용합니다. 저장된 계산 결과가 없는 수식은 원본 수식과 셀 값을 포함한 오류로 표시합니다. 이 경우 Excel에서 재계산 후 저장해야 합니다. 프로그램이 Excel 수식을 직접 실행하지는 않습니다.
- 규격 값은 공란도 허용합니다. 제품의 공장과 품명, 원재료의 재질은 공란을 허용하지 않습니다. 같은 키의 이월·재고 중복행은 합산합니다.
- 기존 열 별칭 `입고일자`, `출고일자`, `거래일자`, `날짜`, `품목명`, `입고수량` 등도 인식합니다. 같은 표준 열에 해당하는 열을 둘 이상 제공하면 오류입니다.
- 특정 파일에만 있는 품목은 UI에 표시하고 없는 내역을 0으로 처리합니다. 신규/소진 품목도 가능하므로 이 항목 자체가 출력을 막지는 않습니다. 공장·품명·규격의 띄어쓰기나 오타 여부를 확인해 주세요.

폴더 로드는 다음처럼 계정과 파일 종류가 모두 포함된 파일명을 매칭합니다. 후보가 여러 개면 임의 선택하지 않으며 해당 슬롯을 비웁니다.

```text
원재료_이월.xlsx  원재료_입고.xlsx  원재료_재고.xlsx
부재료_이월.xlsx  부재료_입고.xlsx  부재료_재고.xlsx
제품_이월.xlsx    제품_출고.xlsx    제품_재고.xlsx
```

## 계산 및 검증

수량·금액은 읽는 시점에 정수화하고 이후 계산은 `Decimal`, 영업일 계산은 `numpy`를 사용합니다. 영업일은 **월~금**으로 정의하며 공휴일·공장별 휴무일은 별도로 제외하지 않습니다. 원본 입고일·출고일을 변경하지 않습니다.

### 원재료·부재료

`연간 출고수량 = 이월수량 + 입고수량 합계 - 재고수량`을 계산합니다. 기초와 각 입고의 보유 가능 수량에 비례하여 출고수량을 배분하고, 해당 재고가 확보된 뒤 최대 세 번의 주 단위 영업일에 나누어 배치합니다. 수량은 정수 단위로 배분하며 마지막 건에 잔량을 반영합니다. 날짜순으로 다시 정렬한 후 각 출고 시점의 이동평균단가를 적용합니다.

출고금액 합계는 `이월금액 + 입고금액 합계 - 재고금액`과 일치하도록 마지막 출고에서 원 단위 단수를 처리합니다. 입력 기말금액이 이동평균 평가와 다르고 그 차이가 단수 범위를 초과하면 오류로 표시합니다. 12월 31일처럼 해당 입고 이후 연내 영업일이 없는 재고는 출고 배분에 사용하지 않으며, 다른 보유량으로도 출고수량을 충당할 수 없으면 오류입니다.

### 제품

`연간 입고수량 = 재고수량 + 출고수량 합계 - 이월수량`을 계산합니다. 같은 날짜의 출고수량을 합산하고, 부족분을 당일 출고 전에 입고합니다. 연말에 남겨야 하는 추가 수량은 연내 마지막 영업일에 입고합니다. 모든 거래는 `일자 → 기초이월 → 입고 → 출고 → 기말재고` 순서입니다. 같은 날짜의 모든 입고가 출고보다 먼저 나옵니다.

기말수량이 양수이면 `재고금액/재고수량`, 아니면 기초수량이 양수일 때 `이월금액/이월수량`을 기준단가로 적용합니다. 둘 다 0이면 기준단가는 0이며 UI에 확인 항목으로 표시합니다. 각 입출고 금액은 수량×기준단가를 원 단위 사사오입하고 마지막 실제 거래 금액에 잔액을 반영하여 기말 수량·금액을 정확히 맞춥니다.

기초와 기말 평가단가가 다르면 금액 차이가 단순 반올림 범위를 넘을 수 있습니다. 이 경우 UI에 평가 기준 확인 항목을 표시하며 출력 엑셀에는 해당 문구를 넣지 않습니다. 마지막 거래금액이 음수가 되거나 거래 중 음수 금액/수량 재고가 발생하는 등 조건을 만족할 수 없는 원본은 출력하지 않습니다.

### UI 전용 검증

수량 역전, 원·부재료 금액 역전, 품목 키 미일치, 수량·금액 등식, 동일 일자 정렬, 거래별 음수 잔고 및 수량 0/금액 잔존을 검사합니다. 검증 통과 시 일자별 마이너스 재고 0건을 표시합니다. 거래별 검사로 하루 중의 선출고도 확인합니다. 원본 파일은 수정하지 않습니다.

행별 오류는 해당 파일의 여러 오류를 한 번에 표시합니다. 품목 열에는 `[입고] 볼트 / M8`처럼 파일 구분과 품명을 표시하고, 검증 내용에는 파일명·실제 엑셀 행 번호·읽은 원본 값·오류 원인을 표시합니다. 행 번호는 **원본 DataFrame 인덱스 + 2**이며 중간 빈 행을 건너뛰어도 바뀌지 않습니다. 계산 오류에는 파일별 정수화 합계와 원본 행의 값을 함께 표시합니다(파일별 처음 3건, 나머지 건수 안내). 긴 내용은 셀 위에 마우스를 올리면 전체 내용을 확인할 수 있습니다. 이러한 진단 정보는 인쇄용 엑셀에 포함되지 않습니다.

입력에 없는 거래일은 정해진 배분 규칙에 따른 계산 결과입니다. 거래 근거와 평가 기준은 출력 전 검토해 주세요. 검증 메시지는 앱에만 표시되며 엑셀에 검증 시트, 설명, 비고를 추가하지 않습니다.

## 인쇄용 엑셀

시트는 `수불집계표`, `원재료 수불부`, `부재료 수불부`, `제품 수불부` 총 4개입니다.

| 상세 시트 | 식별 열 | 공통 숫자 열 |
| --- | --- | --- |
| 원재료 수불부 | 일자, 구분, 재질 | 입고수량·단가·금액 / 출고수량·단가·금액 / 재고수량·단가·금액 |
| 부재료 수불부 | 일자, 구분, 품명, 규격 | 동일 |
| 제품 수불부 | 일자, 구분, 공장, 품명, 규격 | 동일 |

18pt 굵은 밑줄 제목 `2022년도 재고수불부`, 회사명·대상기간·구분, 선택 결재란(담당/검토/승인)을 출력합니다. 표 헤더는 6행이며 7행부터 거래행입니다. 각 품목 아래 회색 `[ 소계 ]` 행을 출력하되 구분 열은 비워두어 거래행에는 네 가지 표준 명칭만 표시합니다. 일자는 `yyyy-mm-dd`, 수량·단가·금액은 `#,##0` 형식입니다. 수량·금액은 입력부터 정수이며 계산 단가는 소수를 유지하고 출력 형식에 따라 표시됩니다.

A4 가로, 1페이지 너비/세로 자동, 매 페이지 1~6행 반복, 좌우 0.3인치 여백, 바닥글 `- &P / &N -`, 숫자 우측 정렬, 얇은 실선과 굵은 외곽선을 적용합니다. 계정별 열 수에 맞춰 제목·결재란·인쇄 영역도 달라집니다. 총괄 합계행은 금액만 합산합니다.

회사명·재질·공장·품명 등 입력 문자열에 금지 문구(`역산`, `추정`, `자동생성`, `보정`)가 있으면 저장을 거부합니다. 문자열은 수식으로 실행되지 않는 텍스트로 저장합니다. Excel 숫자 정밀도는 15자리이므로 이를 넘는 규모의 수량/금액에는 적합하지 않습니다. 실제 페이지 수는 Excel·프린터·글꼴에 따라 달라질 수 있습니다.
