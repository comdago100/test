현장 작업자 빠른 안내

무선 스캐너는 지시서를 읽는 장치입니다.
처리한 제품 개수는 작업자가 입력합니다.

  1. PC에서 현장 스캔을 엽니다.
    무선 수신기 또는 블루투스로 연결한 스캐너가 PC에 문자처럼 입력되는지 확인합니다.
  2. 작업지시 번호 칸을 누르고 스캔합니다.
    Enter가 함께 입력되면 조회됩니다. 자동 조회되지 않으면 작업 조회를 누릅니다.
  3. 조회된 지시서와 공정을 확인합니다.
    지시번호·품목이 맞는지 보고, 이번에 실제 완료한 공정을 선택합니다.
  4. 이번 처리 수량을 입력합니다.
    예: 지금 정상 완료한 수량이 17개이면 17을 입력합니다. PC 키보드나 숫자 키패드를 사용합니다.
  5. 「공정명 수량 기록」을 누릅니다.
    성공 안내와 누적 수량을 확인한 뒤 다음 작업을 진행합니다.
다른 지시서를 찍기 전에는 입력 위치부터 확인하세요.

조회 후에는 수량 칸에 커서가 있을 수 있습니다. 다른 지시서는 상단의 작업지시 번호 칸을 다시 눌러 스캔합니다. 바코드가 수량 칸에 입력되었다면 저장하지 말고 지웁니다.

휴대폰을 사용하는 경우

기본 카메라로 지시서 QR을 읽고 링크를 열면 해당 작업이 조회됩니다. 공정 선택 → 이번 수량 입력 → 수량 기록 순서는 PC와 같습니다. 웹의 카메라로 스캔도 사용할 수 있습니다.

별도 PC 스캐너 프로그램을 사용하는 경우

지시서 조회 후 해당 공정과 처리 가능 수량을 확인하고 이번 수량 기록을 누릅니다. 불량은 불량 등록 / 처리 (웹 화면)에서 처리하고 PC에서 지시서를 다시 조회합니다.

QR을 읽으려면 2차원 코드를 지원하는 스캐너가 필요합니다. 1차원 전용 장비는 기존에 읽을 수 있는 바코드 또는 번호 직접 입력을 사용하세요. 스캔 후 Enter 설정은 장비 설명서에서 확인합니다.

메뉴와 기초정보 준비

메뉴하는 일
생산 현황공정별 누적 수량·출고 잔량·불량·납기 확인
작업지시 관리지시서 등록·수정, 실제 원재료 투입, QR 인쇄
수주 관리고객 주문 등록, 작업지시 생성, 출하 진행 확인
현장 스캔작업 조회, 정상 완료·출고 수량, 불량 처리
라우팅·공정작업에 적용할 공정 순서 등록·수정·복사·삭제
구매·입고원재료 실입고·단가 등록, 수정·취소
재고 현황원재료·완제품 재고, 수불 이력, 원재료 기초 확인
거래처 / 품목 / 원재료 등록업무 화면에서 선택할 코드와 기본정보 준비

처음 사용하는 순서

  1. 거래처 등록: 코드·이름을 입력하고 매출처 / 매입처 / 매출·매입처 / 외주처를 구분합니다. 수주는 매출처, 구매는 매입처가 필요합니다.
  2. 상세정보: 담당자·연락처·사업자정보·사업장 및 납품 주소·결제 조건 등을 필요한 만큼 입력합니다. 거래중지 거래처는 신규 선택에서 제외됩니다.
  3. 품목 등록: 생산하거나 납품할 제품의 코드·이름을 등록합니다.
  4. 원재료 등록: 실제 투입하는 선철·고철 등의 코드·이름을 등록합니다. 원재료 단위는 kg입니다. 등록만으로 재고가 늘지는 않습니다.
  5. 라우팅·공정: 현장에 맞는 공정 순서를 준비합니다. 마지막에는 출고 공정이 한 번 있어야 합니다.
라우팅 예시

주물 제작: 조형·중자 → 용해·주입 → 냉각·해체 → 쇼트 → 절단·사상 → 검사 → 포장 → 출고

완제품 매입·납품: 매입 입고 → 입고검사 → 포장 → 출고

라우팅은 1~30개 공정으로 구성합니다. 수정한 순서는 새 작업지시부터 적용됩니다. 이미 발행된 지시서는 당시 순서를 유지하며, 사용된 라우팅은 삭제 시 사용중지로 보관합니다. 모바일의 상단 메뉴는 가로로 밀어 확인하세요.

기초정보를 먼저 등록하면 다음 화면에서 바로 선택할 수 있습니다.03 / 11

SALES ORDERS

수주를 작업지시에 연결하기

수주 등록→작업지시 생성→현장 작업→출고 자동 집계

1. 수주 등록

  1. 수주 관리에서 수주번호, 매출처, 품목, 수주 수량, 납기일을 입력합니다.
  2. 단가는 선택 사항입니다. 입력하면 수량 × 단가를 원 단위로 반올림한 총액을 표시합니다. 미입력과 0원은 서로 다릅니다.
  3. 수주 저장을 누르고 등록된 수주 목록을 확인합니다.

2. 연결 작업지시 생성

  1. 수주 카드의 작업지시 생성을 누릅니다.
  2. 거래처·품목·미지시 수량·납기일이 기존 작업지시 창에 채워집니다.
  3. 작업지시 번호와 라우팅을 정하고, 이번에 발행할 목표 수량을 확인합니다. 아직 투입하지 않은 자재는 입력하지 않습니다.
  4. 작업지시 저장을 누릅니다. 연결 작업의 목표 수량 합계는 수주 수량을 넘을 수 없습니다.
100개 수주를 처리하는 두 방법

한 작업지시로 진행: 목표 100개짜리 지시서를 만들고, 현장에서 17개·33개·50개 등으로 나누어 작업합니다.

작업지시를 나누어 발행: 납기 회차나 로트별 관리가 필요하면 17개짜리와 83개짜리 등으로 나눕니다. 미지시 수량만큼 추가 발행할 수 있습니다.

3. 진행·출고 확인

연결 작업의 공정 상태를 펼치면 작업지시별 현재 상태·목표·출고 수량을 봅니다. 연결 작업지시 보기로 상세 공정 수량을 확인할 수 있습니다.

누적 출고는 각 작업지시의 마지막 출고 실적 합계입니다. 예를 들어 수주 100개 중 17개를 출고하면 수주 출고 잔량은 83개입니다.

수정할 때

작업지시가 연결된 수주는 거래처·품목을 바꾸거나 삭제할 수 없습니다. 수주 수량은 이미 발행한 합계보다 작게 줄일 수 없습니다. 수주 납기를 수정해도 기존 작업지시 납기는 자동으로 바뀌지 않으므로 필요한 지시서를 별도로 수정합니다.

출고 수량을 수주 화면에 중복 입력하지 않습니다.04 / 11

WORK ORDERS

작업지시와 원재료 투입

작업지시를 직접 등록하는 경우

  1. 작업지시 관리 → 작업지시 등록을 누릅니다.
  2. 작업지시 번호·거래처·품목·라우팅·목표 수량을 선택합니다. 시작일·납기일·단중·용해 번호·재질·메모는 필요한 값을 입력합니다.
  3. 작업지시 저장 후 목록에서 확인합니다.
수주와 연결하려면 수주 관리의 작업지시 생성으로 발행하세요. 작업지시 관리에서 독립적으로 등록한 지시는 수주에 자동 연결되지 않으며, 기존 지시서를 수주에 붙이는 기능은 현재 제공하지 않습니다.

원재료 투입 내역을 기록하는 경우

  1. 해당 작업지시의 수정 / 삭제를 누릅니다.
  2. 원재료 투입 → 자재 추가에서 원재료와 실제 투입 중량(kg)을 입력합니다. 여러 종류의 자재를 추가할 수 있습니다.
  3. 기존 행을 수정할 때는 그 행의 총 투입량으로 바꿉니다. 새 투입분을 별도 행으로 추가할 수도 있으나 같은 투입을 두 방식으로 중복 기록하지 않습니다.
  4. 저장 후 재고 현황에서 사용량과 현재고가 바뀌었는지 확인합니다.
투입 25kg 후 10kg을 추가 투입했다면

기존 25kg 행을 35kg으로 수정하거나, 기존 행을 두고 10kg 행을 추가합니다. 기존 행을 35kg으로 바꾸면서 10kg 행도 추가하면 45kg으로 중복 계산됩니다.

지시서와 QR 인쇄

작업지시 카드의 지시서 / QR 인쇄에서 내용을 확인하고 인쇄합니다. 브라우저 인쇄창에서 PDF 저장도 가능합니다. 새 QR은 운영 주소와 지시번호를 담고 있습니다.

필드와 수량의 의미

항목입력·확인 기준
목표 수량이 작업지시에서 최종 납품할 제품 개수
검사 완료 수량검사로 지정된 마지막 공정의 실적에서 자동 계산. 검사가 없는 라우팅은 0으로 표시
제품 단중제품 한 개의 중량 정보. 입력만으로 자재 투입량이 자동 계산되지 않음
원재료 투입실제 소비한 kg. 제품 완료 개수와 별도로 기록

등록한 작업지시 번호와 라우팅은 발행 후 바꾸지 않습니다. 납기·메모·투입 내역 등은 수정할 수 있으며, 이미 기록된 실적보다 목표 수량을 과도하게 줄이면 저장이 거절됩니다.

제품 개수와 원재료 kg을 구분해 기록하세요.05 / 11

PARTIAL PRODUCTION & SHIPMENT

나누어 생산하고 출고하기

한 번에 만드는 수량은 정해져 있지 않습니다.
같은 작업지시로 여러 차례 기록할 수 있습니다.

매번 「이번에 완료한 수량」만 입력합니다

상황이번 입력저장 후 누적
첫 작업 완료17개17개
이후 23개 추가 완료23개40개
나머지 60개 완료60개100개
추가 23개를 처리한 순간 누적 40개를 입력하면 기존 17개에 40개가 더해집니다. 정상 기록 칸에는 누적 수량이 아니라 이번 수량을 넣습니다.

앞 공정에서 넘어온 수량 안에서 처리합니다

앞 공정 완료가 40개이고 이번 공정 완료가 17개라면, 불량·폐기 등 다른 변동이 없을 때 이번 공정은 23개까지 처리할 수 있습니다. 화면의 처리 가능 수량을 기준으로 확인하세요.

앞 공정을 100개 모두 끝낼 때까지 기다릴 필요는 없습니다. 먼저 완료한 17개를 다음 공정으로 진행하고, 남은 수량은 앞 공정에서 계속 작업하면 됩니다.

작업지시 목표 100개 · 먼저 17개 출고

각 공정에서 17개씩 정상 완료 기록 → 출고 직전 공정 완료 17개 → 마지막 출고를 선택해 17개 기록

누적 출고 17개 / 출고 잔량 83개

이후 남은 물량을 원하는 수량으로 나누어 진행합니다. 전체 목표가 출고되어야 최종 출고 완료가 됩니다.

기존 수량 확인 필요가 표시되는 경우

과거에 상태만 관리했던 지시는 실제 수량을 먼저 확인해야 합니다. 현장 스캔에서 지시서를 조회하고 각 공정의 현재까지 누적 완료 수량을 모두 입력한 뒤 기존 수량 확인 및 시작을 누릅니다. 미처리 공정은 0, 뒤 공정은 앞 공정보다 클 수 없습니다.

이 초기 확인 화면만 누적 수량을 입력합니다. 확인 완료 후 일반 기록은 다시 이번 처리 수량을 입력합니다. 잘못 확인한 초기 수량은 임의로 추가 입력해 맞추지 말고 운영 담당자에게 정정을 요청하세요.

저장 결과가 불확실하면 같은 기록 확인 / 재시도로 확인합니다. 새 기록으로 중복 입력하지 말고, 결과를 확인한 뒤 다음 작업으로 이동합니다.

QUALITY · REWORK · SCRAP

불량이 발생했을 때

현장 스캔에서 작업지시서를 조회하고 실제 불량을 발견한 공정을 선택한 뒤 불량 관리를 사용합니다.

1. 정상 완료 입력 여부를 먼저 확인합니다

재고 숫자 읽는 법

원재료 재고 · kg

현재고 = 구매 입고 + 기초조정 − 작업지시 투입

입고가 100kg이고 투입이 25kg이면 현재고는 75kg입니다. 입고를 90kg으로 수정하면 65kg으로 바뀝니다. 숫자를 별도로 덮어쓰지 않고 현재 원본 기록을 다시 합산합니다.

처음 도입할 때 기초재고 확인

  1. 기존 입고·투입 자료의 중복이나 누락을 먼저 확인하고, 실제 남아 있는 kg을 실사합니다.
  2. 재고 현황 → 원재료 재고 → 기초재고 확인을 누릅니다.
  3. 실제 보유 수량 (kg)과 실사 메모를 입력하고 기초재고 반영을 누릅니다. 입력값은 조정량이 아니라 현재 실제 보유량입니다.
  4. 저장 뒤 현재고가 실사 수량과 맞는지 확인합니다. 입력 중 입고·투입이 바뀌었다면 창을 닫고 최신 값으로 다시 확인합니다.

예: 구매 0kg, 기존 투입 25kg, 실제 보유 100kg이면 기초조정은 +125kg입니다. 기존 기초조정을 다시 확인하면 대체되며 중복 추가하지 않습니다. 조정량은 음수나 0도 가능하고, 기초 미확인 표시는 실사를 확인하지 않았다는 뜻입니다.
